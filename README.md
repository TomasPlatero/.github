## What I build

### <img src="https://github.com/TomasPlatero/PiCode/blob/master/assets/pi.svg?raw=true" width="18" alt=""/> **[PiCode](https://github.com/Tomas-Platero/PiCode)**

A VSCodium distribution with the **[Pi](https://pi.dev)** coding agent and **[Gentle AI](https://github.com/Gentleman-Programming/gentle-ai)** inside the editor core — not as a plugin bolted on afterwards.

Pi in the chat, providers connected from settings, memory and skills already there. No setup ceremony, no Copilot. Free and complete.

## How it's built

| Layer | What |
| --- | --- |
| **Editor** | VSCodium — the MIT-licensed source, rebuilt as PiCode |
| **Agent** | Pi (earendil-works/pi) — coding agent with tools, providers, models, skills |
| **Workflow** | ODD — Organic Driven Development, with SDD/OpenSpec where the spec calls for it |
| **Review** | Gentle AI — receipt-driven development, blind dual review, verification discipline |
| **Memory** | Engram — persistent cross-session memory, cross-project knowledge |
| **Platform** | Windows (primary), Linux (full pipeline, nightly CI) |
| **Build** | Bash · gulp · C# / WinUI 3 · .NET · GitHub Actions |
